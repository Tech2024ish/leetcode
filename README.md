```
├── Counting/            # Frequency analysis and counting techniques
├── matrices/            # 2D grid and matrix problems
├── number-theory/       # Math and number theory
├── prefixSum/           # Prefix sum and sliding window
├── sortingAlgotithms/   # Sorting-based problems
└── twoPointers/         # Two-pointer technique
```
